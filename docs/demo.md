# 3 分钟演示脚本

> 目标：一次跑通「桌面浏览器 → Agent 对话 → 任务提醒 → Electron 原生通知 → 手机布局 → PWA 安装」，不出现死链或占位页。

## 演示前准备

- 后端与 MySQL / Redis 已启动，账号已登录或准备好测试账号。
- 桌面浏览器打开 `https://<域名>/`；Electron 安装包已安装。
- 手机与电脑访问同一 HTTPS 站点。
- 在设置页开启浏览器通知（用于 PWA 推送演示）。

## 演示流程

1. **开场（20 秒）**
   - 展示桌面浏览器宽屏布局：聊天、任务、关系、设置。
   - 说明：一套 Vue 源码同时服务桌面浏览器、手机与 Electron，桌面样式在 ≥901px 下不触发媒体查询。

2. **Agent 对话（40 秒）**
   - 新建会话，发送一句需要工具调用的问题（例如“帮我看看今天还有什么任务”）。
   - 展示 SSE 流式输出、工具调用状态 chip、Markdown 渲染。
   - 说明：工具白名单 + 服务端注入 userId + 参数化 SQL。

3. **任务与关系（30 秒）**
   - 新建一个 1 分钟后到点的任务。
   - 展示任务列表、关系阶段与亲密度摘要。
   - 把Electron 主窗口关闭到悬浮球（或切到其他窗口）。

4. **Electron 原生通知（30 秒）**
   - 到点后 Windows 弹出原生通知。
   - 点击通知：主窗口展开并进入任务页。
   - 说明：悬浮球常驻、隐藏主窗口预加载、通知由现有 SSE 驱动；Refresh Token 30 天免登录。

5. **手机响应式（30 秒）**
   - 手机浏览器打开同一网址（或 Chrome DevTools 设备模式）。
   - 展示汉堡抽屉导航、聊天会话抽屉、虚拟形象底部浮层、单列表单。
   - 说明：44px 触控目标、16px 输入字号、横屏压缩。

6. **PWA（20 秒）**
   - 浏览器地址栏出现“安装应用”，安装后从桌面图标独立打开。
   - 收到测试推送并点击跳转任务页（Android Chrome 最稳；iOS 需 16.4+ 且已添加到主屏幕）。

## 技术亮点口径

- 一套代码、三种承载：响应式断点 + Web/Electron 两种构建配置。
- 分环境 Refresh Token：Electron 1h/30d，浏览器 30min/14d；轮换 + 重放撤销 + Redis 会话白名单。
- Electron 安全壳：`contextIsolation + sandbox`、preload 白名单、`safeStorage` 加密 Refresh Token。
- Agent 运行时：SSE 流式 + 工具调用循环 + 上下文裁剪 + 幂等消息。
- 数据与体验：Flyway 迁移、像素舞台、任务/关系/通知闭环。

## 常见演示风险

| 风险 | 处理 |
| --- | --- |
| 通知不弹 | 检查 Windows 专注助手、系统通知权限；确认应用已登录且 SSE 在线 |
| Electron 白屏 | `.env.desktop` 是否为绝对 API 地址；重新 `npm run build:desktop` |
| 手机访问不到 | HTTPS 证书、Nginx 反代、防火墙端口 |
| iOS 无推送 | 必须 16.4+ 且从主屏幕打开 PWA |
| 演示数据为空 | 提前创建会话/任务/关系记录，避免空状态占用时间 |
